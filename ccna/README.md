# CCNA Labs

This section documents my hands-on labs while studying for the Cisco Certified Network Associate (CCNA) certification.

My primary course resource is **Jeremy's IT Lab CCNA course**, supplemented by independent practice and additional networking exercises.

## Lab Documentation

Each lab is documented in my own words and may include:

- Objectives
- Network topology
- Device and interface information
- IP addressing
- Cisco IOS configuration
- Verification commands and results
- Connectivity testing
- Troubleshooting
- Root-cause analysis
- Lessons learned

## Lab Environment

Labs may use:

- Cisco Packet Tracer
- Cisco IOS
- Wireshark
- Other networking tools as introduced during my studies
