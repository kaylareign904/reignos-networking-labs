## 📚 Documentation Approach

I use this repository as both a learning record and a technical portfolio.

Rather than simply uploading completed lab files, I document the reasoning behind the work.

For each lab, I aim to answer:

**What was I trying to accomplish?**

**How did I configure it?**

**How did I verify that it worked?**

**What went wrong?**

**How did I troubleshoot it?**

**What did I learn?**

This approach allows the repository to demonstrate configuration knowledge as well as the troubleshooting and problem-solving process used to reach a working solution.
